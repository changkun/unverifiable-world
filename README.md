# 在无法验证的世界里

> 在没有任何东西能确认你做对了的地方，有限的主体如何行动。

一本关于**不可验证性**的书。核心论点不是「不同领域面对的是同一个问题」——而是更强、也更站得住的命题：

> **不可验证性的来源天差地别，但有限主体被逼出来的应对，反复收敛到同一小套。**

全书的贡献，是那张「同一招在多种行话下的对照表」，外加一个解释：为什么偏偏是这几招。

## 全书脊柱

面对不可验证，你只能动有限的几根杠杆。本书识别出**八招**，每一招攻击「风险 / 信息分解」里的不同一项：

| 招数 | 攻击的是 | 跨域化名（举例） | 经典败法 |
| --- | --- | --- | --- |
| 代理替换 | 你度量什么 | 测试代替正确性证明、benchmark 代替智能、KPI、等价改写 | Goodhart |
| 证书 / 界 | 在一个切片上压不确定性 | PAC 界、数值误差界、类型系统、验到高度 T 的零点 | 界外失效 |
| 神谕入回路 | 补上你没有的验证能力 | 主动学习、人在回路、交互式定理证明 | 神谕本身不可靠 |
| 最优筛查 | 最优地花信息预算 | 实验设计、审计抽样、fuzzing、主动学习采集 | 默认收敛到某一种实现 |
| 衰减 / 围栏 | 失败的爆炸半径 | 沙箱、最小权限、职责分离、熔断 | 围栏被绕过 |
| 标定 / 概率接受 | 显式给残余风险定价 | Miller–Rabin、conformal prediction | 标定漂移 |
| 留痕 / 可审计 | 把检查从事前挪到事后 | Merkle 树、审计日志、预注册 | 没人真去查 |
| 冗余 / 共识 | 让失败去相关 | 拜占庭容错、同行评审、副本、第二诊疗意见 | 失败其实相关 |

这根脊柱（风险分解 × 八招）是否成立，是全书最大的赌注。诚实的交付边界：目前没有证据说它是**定理**；它至少是一个很强的**经验模式**。第 14 章正面处理这个问题。

## 不可验证的五副面孔

书必须先把差异讲透，才配谈综合：

1. **不可判定** —— 原则上没有判定程序（停机问题、Rice 定理）
2. **难解** —— 能验但代价爆炸（如 RH 一类可查到有限高度却证不出的）
3. **部分可观测** —— 状态看不全（用户真实偏好、组织里分布的知识）
4. **预算受限** —— 能验，但没那个时间 / 算力 / 样本
5. **对抗性** —— 系统主动抵抗验证（会欺骗的智能体、有隐藏信息的市场）

## 结构

详见 [`SUMMARY.md`](SUMMARY.md)。四部按论证推进排，不按主题堆：

- **第一部 不可验证** —— 立问题，并讲清来源各不相同（综合的信用额度）
- **第二部 化身** —— 走进四个现场，让招数在真实语境里浮现（招数嵌在 domain 里、彼此缠绕）
- **第三部 收敛** —— 把每一招抽成纯形式、横跨所有领域并置（那张对照表，全书贡献）
- **第四部 杠杆** —— 回答「为什么偏偏是这几招」，并落到认识论

## 谱系（定位用）

- 最近的祖宗：Herbert Simon,《The Sciences of the Artificial》（有限理性、主体与环境的界面）
- 组织那章：James C. Scott,《Seeing Like a State》（legibility）
- 要警惕的反面：GEB —— 跨域类比漂亮但常被批「只是类比」；本书与它的区别，必须就是那根能被压力测试的脊柱
